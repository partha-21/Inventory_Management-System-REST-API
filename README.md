# Inventory Management System — REST API

A production-oriented **Inventory Management REST API** built with **Java, Spring Boot, Hibernate/JPA, and MySQL**, designed to demonstrate scalable backend architecture, clean API design, and enterprise-style inventory workflows. The system manages products, categories, suppliers, stock levels, inventory transactions, and reporting through a modular Spring Boot backend.

## Project Showcase

* **RESTful API architecture** with structured resource-based endpoints
* **Layered Spring Boot architecture** (Controller → Service → Repository)
* **Hibernate/JPA** for ORM and relational data management
* **DTO-driven request and response models**
* **Global exception handling** with custom error responses
* **Inventory transaction tracking** for stock movement history
* **Reporting and analytics endpoints**
* **Normalized relational database design**
* **Modular and maintainable backend codebase**
